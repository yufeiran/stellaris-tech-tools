Tech Tree & Research Planner — Browser tree

1. Select the intended playset in the Stellaris launcher.
2. Windows: double-click OPEN-TECH-TREE.bat.
   Mac: OPEN-TECH-TREE.command, or sh OPEN-TECH-TREE.sh.
   Linux: sh OPEN-TECH-TREE.sh.
3. Check the detected game/playset/sources and press Enter.

The tree opens in your default browser. If it does not open automatically,
open the printed http://127.0.0.1:PORT/ address. Keep the terminal window open;
close it or press Ctrl+C to stop. No Python, Node or compiler is needed.

Drag to pan, scroll to zoom, search in Chinese/English or by technology ID.
Choose All fields for cross-field dependencies. Source filtering is optional.

For offline viewing, choose Export PDF, then Save as PDF in the print dialog.
The export includes the current field and filters. Choose All fields first
for the whole tree. Full Chinese/English names and IDs remain searchable text;
use Chrome Ctrl+F in the saved PDF and zoom to read the vector tree.

This is a read-only snapshot of source definitions, not current save progress,
research cards or in-game goals. It does not change your planner/launcher/saves.
Rerun after source updates or switching playsets. Standard definitions from
source mods are collected without an ID list; unusual scripts may be unsupported.
Mod icons currently use field placeholders; not every new Mod text has pinyin.
Special DLC/empire/event conditions remain game-controlled. Server is local only.

Browser working reports are stored in ~/TTE-Research-Planner outside Steam.
They contain selected source paths; keep them local unless you choose to share.
INSTALL-TECH-ADAPTER is the separate in-game planner adaptation tool.

科技树与科研规划 — 浏览器科技树

在启动器选好播放集，运行 OPEN-TECH-TREE（Windows 用 .bat，Mac 用 .command
或 sh OPEN-TECH-TREE.sh，Linux 用 sh OPEN-TECH-TREE.sh），核对来源后按回车。
浏览器会自动打开；若没有，请手动打开打印的 127.0.0.1 地址。
保持终端窗口打开；关窗口或按 Ctrl+C 停止。无需 Python、Node 或编译器。

支持拖动、缩放、中英文与 ID 搜索，全部学科同图，查看跨科前置关系。
离线查看可点“导出 PDF”，在打印窗口选“另存为 PDF”。按当前学科与筛选导出；
导出全图前请选择“全部”。文件保留完整中英文名称与科技 ID 的文字层，
在 Chrome 中可按 Ctrl+F 搜索，并可放大查看矢量文字和连线。
只读科技资料，不同步存档进度、抽卡或游戏内目标，不修改规划器、播放集和存档。
来源更新或更换播放集后重新运行。标准科技无需逐个维护 ID，特殊脚本可能不支持。
Mod 图标暂用学科占位图标；新 Mod 文本的完整拼音不保证。特殊解锁条件由游戏判断。
工作报告位于用户主目录 TTE-Research-Planner，包含来源路径，请自行决定是否分享。
INSTALL-TECH-ADAPTER 是另一个用于适配游戏内规划器的入口。
