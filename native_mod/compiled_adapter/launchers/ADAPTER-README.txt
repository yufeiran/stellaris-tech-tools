Tech Tree & Research Planner — Technology Adapter

This optional tool is included in the Workshop download. No extra download,
Python, or compiler is needed. Use it for a source-Mod combination that is not
covered by the built-in planner. It does not run automatically in the game.

1. Select your source Mods in the Stellaris launcher. Close the game/launcher.
2. Open this item's local Workshop folder (281990/3818261596).
   Windows: double-click INSTALL-TECH-ADAPTER.bat
   Mac: in Terminal, type sh and drag INSTALL-TECH-ADAPTER.sh into the window.
        INSTALL-TECH-ADAPTER.command is also provided if Finder can execute it.
        Intel / Apple Silicon is selected automatically.
   Linux: sh INSTALL-TECH-ADAPTER.sh
3. Check the detected paths and current playset. Press Enter to build.
4. When complete, keep THIS Workshop planner enabled after the source Mods.
   Reopen the launcher/game. No Local Mod or playset switch is required.

The tool updates only this Mod's own tte_runtime.zip, after a verified backup
under ~/TTE-Research-Planner/Workshop-backups. Working files stay outside Steam.
Your source Mods, registrations and playsets are not modified. Steam updates
can replace personalized data; rerun the tool after a planner/source-Mod update
or after changing the source combination. Never run it while the game or
launcher is open. No elevated/administrator rights are requested by the tool.
Special scripted unlocks may require individual support. No automatic claim of
compatibility with every Mod is made. Keep the generated source combination
fixed during a campaign, as with other technology Mods.
For multiplayer, all players need the same source combination AND generated
planner data; sharing an item subscription alone does not make checksums equal.

If detection fails, enter the requested path, or use e to edit detected defaults.
On macOS/Linux, if the launcher file is not executable, open Terminal and run
sh followed by the path to INSTALL-TECH-ADAPTER.sh. The tool does not request
administrator rights or modify operating-system security settings.
