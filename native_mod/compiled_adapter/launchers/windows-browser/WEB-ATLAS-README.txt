Tech Tree & Research Planner — Browser tree (Windows x64)

1. Select the intended playset in the Stellaris launcher.
2. Double-click OPEN-TECH-TREE.bat in this Workshop folder.
3. Check the detected game/playset/mods and press Enter.

The tree opens in your default browser. If needed, open the printed
http://127.0.0.1:PORT/ address manually. Keep the terminal open; close it
or press Ctrl+C to stop. No Python, Node or compiler is needed.

Drag to pan, scroll to zoom, search in Chinese/English or by technology ID.
All fields shows cross-field dependencies. Filter by source Mod if desired.

For offline viewing, choose Export PDF, then Save as PDF in the print dialog.
The export includes the current field and filters. Choose All fields first
for the whole tree. Chinese/English names and IDs remain searchable text:
open the saved PDF in Chrome and use Ctrl+F. Zoom to read the vector tree.

This is a read-only snapshot of technology definitions. It does not show
current save progress, offered cards or in-game goals, or change your planner,
launcher or saves. Rerun after source updates or switching playsets.
Standard Mod definitions are collected without an ID list; unusual scripts
may be unsupported. Special DLC/empire/event conditions remain game-controlled.
Mod icons currently use field placeholders; new Mod text may lack pinyin.

Only this optional browser entry is Windows-only. Existing game Mod
and INSTALL-TECH-ADAPTER entries retain their Windows/Mac/Linux functionality.
The server is local only. Reports in ~/TTE-Research-Planner contain source
paths; keep them local unless you choose to share them.

浏览器科技树（Windows x64）

在启动器选好播放集，双击本目录 OPEN-TECH-TREE.bat，核对来源后按回车。
浏览器自动打开；若没有，请打开打印的 127.0.0.1 地址。
保持终端打开；关闭窗口或按 Ctrl+C 停止。无需 Python、Node 或编译器。

支持拖动、缩放、中英文和 ID 搜索，全部学科同图，查看跨科前置和来源筛选。
离线查看：点击“导出 PDF”，在打印窗口选择“另存为 PDF”。按当前学科与筛选
导出，导出全图前请选择“全部”。文件保留中英文名称与科技 ID 的文字层，
用 Chrome 打开后可按 Ctrl+F 搜索，也可以放大查看矢量科技树。
只读科技资料，不显示存档进度、抽卡或游戏内目标，不修改规划器、播放集和存档。
来源更新或换播放集后重跑。标准科技自动收录，特殊脚本不保证。
Mod 图标暂用学科占位图标，新 Mod 文本的拼音不保证；解锁资格由游戏判断。

目前仅浏览器入口限 Windows；游戏内功能与 INSTALL-TECH-ADAPTER
保留原有 Windows/Mac/Linux 支持。工作报告位于主目录 TTE-Research-Planner，
包含来源路径，请自行决定是否分享。
